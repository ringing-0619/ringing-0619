## 数据分析与 BI

### [AWG 零售分析](https://github.com/ringing-0619/awg-program-participation)

使用 Python 清洗整合 **54 万余条月度源记录**，构建上市窗口销售与门店覆盖率指标，并通过 OLS 交互回归分析 **9.3 万条门店商品观测，覆盖 5 个品牌和 9 个区域**。将分析发现与建议纳入两轮客户汇报，连接数据准备、指标衡量与业务决策。

### [USDC 钱包集中度分析](https://github.com/ringing-0619/usdc-wallet-concentration)

在团队项目中负责 Dune SQL 分析，衡量滚动 180 天内以太坊地址的 USDC 转账活动集中度。使用 CTE、排序与累计窗口函数生成洛伦兹曲线坐标，并明确地址参与频次的指标定义。

### [UIUC Statistics Datathon](https://github.com/ringing-0619/uiuc-statistics-datathon)

基于团队呼叫中心预测流程整理的公开演示，涵盖日级梯度提升预测、半小时时段分配与按时间顺序的回测。可运行流程使用独立生成的合成数据，并在导出预测前校验时间覆盖、输出数值与比率。
